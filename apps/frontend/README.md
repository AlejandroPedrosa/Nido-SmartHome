# Frontend — NIDO SmartHome

Aplicación cliente desarrollada con React 19, TypeScript, Vite, Tailwind CSS, shadcn/ui y Zustand.

## Estructura proyectada
* `src/components/`: Componentes reutilizables de UI y formularios.
* `src/pages/`: Vistas de la aplicación (Login, Register, Dashboard, Products, Containers, Recipes, ShoppingList, Settings).
* `src/stores/`: Stores globales de estado con Zustand.
* `src/services/`: Clientes HTTP para comunicación con la API REST.
* `src/hooks/`: Hooks personalizados.
